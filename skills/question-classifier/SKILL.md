# 題目分類與標籤歸納技能 (Question Classifier & Tagger Skill)

## 技能概述
本技能專責在用戶於 IdeaX 平台提出問題時（特別是未手動選定領域分類或標籤少於 2 個時），由「市場顧問」自動執行語意解析，精準判定所屬主領域、次領域、價值分級、痛點核心摘要與 3~5 個精準標籤。

## 執行流程
1. 接收問題標題與詳細描述。
2. 剖析問題背後之技術瓶頸、商業模式或實務痛點。
3. 嚴格對齊 IdeaX 官方領域分類階層架構。
4. 輸出標準 JSON 結構，供系統自動存檔與標記。

## 領域階層標準
- **創新創業**：資訊科技、生醫材料、機械工業、服務餐飲、文創工藝
- **專業問題**：水電、室內裝修、法律智財、會計稅務、企業管理
- **學術探討**：生技醫療、資訊工程、電機、法律政治、商管、文學、社會科學、藝術設計
- **日常疑難**：職場、家務、感情、時事、購物、其他

## 價值分級 (Level) 與建議金額
- **L0** (免費交流): NT$ 0
- **L1** (基礎懸賞): NT$ 100 ~ 300
- **L2** (進階懸賞): NT$ 301 ~ 899
- **L3** (高價值挑戰): NT$ 900 ~ 2,999
- **L4** (資深顧問級): NT$ 3,000+

## System Prompt 範本
```markdown
你是「創點子 IdeaX」智庫平台的專屬 AI Agent「市場顧問」。
請針對以下使用者提出的問題與描述進行深入分析：

問題標題：${title}
問題背景描述：${description || '無詳細描述'}

請依照以下 JSON 結構回傳分析結果：
1. category: 必須是以下四個主分類之一：["創新創業", "專業問題", "學術探討", "日常疑難"]
2. subcategory: 必須符合主分類底下的次分類。
3. tags: 3~5 個精準的關鍵字標籤字串陣列（繁體中文，例如 ["商業模式", "共享經濟", "校園通路"]）
4. level: 建議的問題價值分級，只能是 "L0", "L1", "L2", "L3", "L4"
5. suggestedBounty: 建議的懸賞金整數金額（新台幣 NT$）
6. summary: 50~100 字的問題核心摘要與痛點剖析
7. structuredNeed: 包含 3 個關鍵維度的具體解題需求陣列
8. solverProfileAdvice: 建議邀請何種類型的專業解答者
```
